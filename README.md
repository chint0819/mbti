# 🔮 〇〇診断メーカー

「〇〇」に好きな言葉を入れるだけで、あなただけのオリジナル性格診断が作れるWebアプリです。
「ラーメン診断」「戦国武将診断」「ディズニー診断」——テーマは自由。数問に答えると、テーマに合わせたクリエイティブな診断結果が表示されます。

2つのモードがあります:

| モード | 質問 | 結果 | 必要なもの |
|---|---|---|---|
| **AIモード** | テーマ専用にAIが生成(例: ディズニー →「パークに着いたら最初にすること?」) | テーマ内のキャラクター(例: ミッキーマウス、プーさん)+性格分析 | Anthropic APIキー + Cloudflare Worker([SETUP-AI.md](SETUP-AI.md) 参照・15分) |
| **汎用モード** | 心理4軸の固定12問 | 16タイプ+テーマ装飾(例:「愛されリーダー系ラーメン」) | なし(既定・AIモード失敗時のフォールバック) |

## デモの動かし方

ビルド不要の静的サイトです。`index.html` をブラウザで開くだけで動きます。

```bash
# ローカルサーバーを立てる場合
python3 -m http.server 8000
# → http://localhost:8000
```

GitHub Pages で公開する場合は、リポジトリの Settings → Pages でブランチを選ぶだけです。

## 「結果がある程度正しい」を実現する設計

テーマが何であっても結果が信頼できるように、**採点の骨組みを心理尺度に固定**しています。

1. **4軸モデルが共通の背骨** — どちらのモードも、ビッグファイブ理論(性格心理学で最も実証的な支持があるモデル)の因子を参考にした4軸で採点します。
   - エネルギーの向き: 外向(E) / 内向(I) … 外向性
   - ものの見方: 探究(N) / 現実(S) … 開放性
   - 判断のしかた: 論理(T) / 共感(F) … 協調性
   - 進め方: 計画(J) / 柔軟(P) … 誠実性
2. **汎用モード**: 固定12問(各軸3問・逆転項目つきで黙従傾向を軽減)→ 16タイプの性格コンテンツ。テーマはタイプ名などの「見せ方」にだけ決定的に合成されるので、共有リンクでも結果がぶれません。
3. **AIモード**: AIには「テーマ仕立てだが必ず4軸のどれかを測る質問」を8問(各軸2問・選択肢に±2〜±1の重み)と、「キャラクターの広く知られた性格に基づく4文字タイプ」を割り当てた結果10〜16個を生成させます(JSON Schemaで構造を強制)。回答→軸スコア→最も距離の近いタイプのキャラクター、というマッチングは汎用モードと同じ数理です。
4. **どちらも軸ごとの傾き(%)を結果画面に表示** — 診断の根拠が見えるようにしています。

※ 簡易尺度なので、あくまでエンタメ用途です(アプリ内にも明記)。

## 機能

- テーマ自由入力 + プリセットテーマのワンタップ選択
- 12問・5件法(リッカート尺度)、戻るボタン付き、進捗バー
- 16タイプの診断結果: タイプ名 / キャッチコピー / 性格分析 / 4軸スコアバー / 強み / アドバイス / 相性タイプ
- 結果のシェア(Web Share API、非対応環境ではリンクコピー)
- 結果はURLに埋め込まれるので、リンクを開けばそのまま結果画面が復元される
- レスポンシブ + ダークモード対応

## 構成

```
index.html         画面(スタート / 生成中 / 質問 / 結果)
css/style.css      スタイル(ライト/ダーク対応)
js/config.js       設定(AIモードのエンドポイントURL)
js/questions.js    汎用モードの質問バンク(4軸 × 3問、逆転項目つき)
js/engine.js       採点エンジン(軸スコア計算・タイプ判定・キャラマッチング・相性)
js/themes.js       汎用モードの16タイプコンテンツとテーマ合成
js/ai.js           AI生成パックの取得・検証・キャッシュ
js/app.js          画面遷移・描画・共有URL
worker/worker.js   AI生成プロキシ(Cloudflare Worker、SETUP-AI.md 参照)
tests/run-tests.js ロジックのテスト
```

## テスト

```bash
node tests/run-tests.js
```

採点の境界値、逆転項目の効果、16タイプのコンテンツ網羅、テーマ合成の安定性(共有リンク整合)などを検証します。
