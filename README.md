# 🔮 〇〇診断メーカー

「〇〇」に好きな言葉を入れるだけで、あなただけのオリジナル性格診断が作れるWebアプリです。
「ラーメン診断」「戦国武将診断」「妖怪診断」——テーマは自由。12問に答えると、テーマに合わせたクリエイティブな診断結果が表示されます。

## デモの動かし方

ビルド不要の静的サイトです。`index.html` をブラウザで開くだけで動きます。

```bash
# ローカルサーバーを立てる場合
python3 -m http.server 8000
# → http://localhost:8000
```

GitHub Pages で公開する場合は、リポジトリの Settings → Pages でブランチを選ぶだけです。

## 「結果がある程度正しい」を実現する設計

テーマが何であっても結果が信頼できるように、**診断の中身と見せ方を分離**しています。

1. **質問は固定の心理尺度** — 12問はビッグファイブ理論(性格心理学で最も実証的な支持があるモデル)の因子を参考にした4軸(各3問)の簡易尺度です。テーマによって質問は変わりません。
   - エネルギーの向き: 外向(E) / 内向(I) … 外向性
   - ものの見方: 探究(N) / 現実(S) … 開放性
   - 判断のしかた: 論理(T) / 共感(F) … 協調性
   - 進め方: 計画(J) / 柔軟(P) … 誠実性
2. **逆転項目を混ぜて回答バイアスを軽減** — 各軸に逆キーの質問を入れ、「なんでも『そう思う』と答える」黙従傾向の影響を減らしています。
3. **結果の中身はスコアだけで決まる** — 性格分析・強み・アドバイスは4軸スコアから決まる16タイプのコンテンツで、軸ごとの傾き(%)も表示します。
4. **テーマは「見せ方」にだけ使う** — タイプ名(例:「愛されリーダー系ラーメン」)や例えテキストにテーマを合成します。同じテーマ×同じタイプなら常に同じ表示になる決定的な生成なので、共有リンクを開いても結果がぶれません。

※ 12問の簡易尺度なので、あくまでエンタメ用途です(アプリ内にも明記)。

## 機能

- テーマ自由入力 + プリセットテーマのワンタップ選択
- 12問・5件法(リッカート尺度)、戻るボタン付き、進捗バー
- 16タイプの診断結果: タイプ名 / キャッチコピー / 性格分析 / 4軸スコアバー / 強み / アドバイス / 相性タイプ
- 結果のシェア(Web Share API、非対応環境ではリンクコピー)
- 結果はURLに埋め込まれるので、リンクを開けばそのまま結果画面が復元される
- レスポンシブ + ダークモード対応

## 構成

```
index.html        画面(スタート / 質問 / 結果)
css/style.css     スタイル(ライト/ダーク対応)
js/questions.js   質問バンク(4軸 × 3問、逆転項目つき)
js/engine.js      採点エンジン(軸スコア計算・タイプ判定・相性)
js/themes.js      16タイプのコンテンツとテーマ合成
js/app.js         画面遷移・描画・共有URL
tests/run-tests.js ロジックのテスト
```

## テスト

```bash
node tests/run-tests.js
```

採点の境界値、逆転項目の効果、16タイプのコンテンツ網羅、テーマ合成の安定性(共有リンク整合)などを検証します。
